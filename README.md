# 📌 Project Overview
The system consists of multiple parts working together to manage daily operations of a childcare center, including children enrollment, subscriptions, attendance tracking, and role-based dashboards.

## The project is divided into:
**1. Backend (API Server)** 

**2. Frontend:**
- Public Website
- Internal Dashboard


## Architecture Overview
**Backend:** RESTful API responsible for business logic, authentication, and data management.

**Frontend:**

Public Website: Used by parents/guardians for basic interactions.

Dashboard: Internal system for administrators, directors, and staff.

Database: Centralized data storage for users, children, subscriptions, and attendance.

**The architecture emphasizes:**

Modular structure

Role-based access control

##  User Roles

The system supports multiple roles, each with different permissions:

* Admin – Full system access and configuration

* Director – Children and staff management

* Teacher – Classroom and attendance management

* Parent / Guardian – Child registration and resubscription
